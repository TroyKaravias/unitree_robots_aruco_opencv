🤖 Unitree Robot — Commands Cheatsheet

🦾 G1 Robot SSH into Jetson first

SSH into the Jetson (password: 123)
ssh unitree@192.168.123.164
Start the camera + ArUco scanner (with auto-restart monitor)
nohup bash /home/unitree/g1_scanner_monitor.sh > /dev/null 2>&1 &
Kill stuck script and restart with alternate device (/dev/video5)
pkill -f g1_camera_view.py; pkill -f g1_scanner_monitor.sh G1_CAMERA_DEVICE=/dev/video5 nohup bash /home/unitree/g1_scanner_monitor.sh > /dev/null 2>&1 &
Watch the live log
tail -f /tmp/g1_camera.log
View camera stream in browser
http://192.168.123.164:8080/

🐕 Go2 Robot Run on your laptop

Navigate to the project folder
cd /home/troy81004/unitree_robots_aruco_opencv
Run the ArUco scanner script
python3 scripts/go2/go2_aruco_scan.py
Run with a custom Go2 IP (if not 192.168.8.181)
UNITREE_ROBOT_IP=<actual_ip> python3 scripts/go2/go2_aruco_scan.py
Run the autonomous script
python3 scripts/go2/go2_aruco_autonomous.py

🐕 Go2 Autonomous Mode Run on your laptop

Start the autonomous script (opens MJPEG stream automatically)
python3 scripts/go2/go2_aruco_autonomous.py
Force headless mode (stream only, no OpenCV window)
HEADLESS=1 python3 scripts/go2/go2_aruco_autonomous.py
View stream & control — via Go2 hotspot (WiFi)
http://192.168.12.1:8080/
View stream & control — via Ethernet
http://192.168.123.170:8080/
Run with custom IP and custom stream port
UNITREE_ROBOT_IP=<ip> STREAM_PORT=8081 python3 scripts/go2/go2_aruco_autonomous.py

Open the control UI in your browser — via Go2 hotspot (direct WiFi)
http://192.168.12.1:8080/
Open the control UI — via ethernet (if connected by cable)
http://192.168.123.170:8080/
What the UI gives you
• Live camera feed (MJPEG stream) • Start Patrol button — Go2 begins scanning and acting on ArUco markers • Stop Patrol button — halts autonomous movement • Live ArUco scan log — shows detected marker IDs in real time

🔧 Diagnostics Run on Jetson (G1)

Check if the script is running
pgrep -a -f g1_camera_view.py
List all available camera devices
v4l2-ctl --list-devices
Kill everything and start fresh
pkill -f g1_camera_view.py; pkill -f g1_scanner_monitor.sh
Check the last 30 lines of the camera log
tail -30 /tmp/g1_camera.log
